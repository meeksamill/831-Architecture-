# 831 Architecture

*Updated Nov-7, 2026. Current facts only; changes under Transition.*

The architecture documents of what became The 831 Company LLC: the
system designs from the build's first season — the swarm, the gate, the
record discipline — kept as the design record they are.

These documents describe the architecture as designed. The system as it
stands today — what is built, what is live, what is held, and what is
not claimed — is stated in the company spine, `831Company/831-
formalities`, which governs where the two differ. The company's working
repositories are under the `831Company` organization; this repository
remains the early design record under the founder's account.
